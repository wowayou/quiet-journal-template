# 设计基线与可选扩展

阅读页与文章列表沿用 v1.0 的文字单栏、等宽字体、强调色标题列表和虚线链接。2026-10-26 按作者反馈精简：首屏取消卡片（宽屏文字左、线描右，窄屏线描在上），页脚恢复 v1.0 的居中纵向排列，图片一律不超出正文栏。样式与线描独立编写；参考与边界见 [RESEARCH.md](RESEARCH.md)，取舍见 [DECISIONS.md](DECISIONS.md)，日常修改见 [CUSTOMIZE.md](CUSTOMIZE.md)。

## 原则

1. **文字和照片仍是主角**：文章列表和阅读页不加卡片、阴影、标签或装饰动画；首页只保留一幅静态线描，不用卡片边框。
2. **一种基线**：首屏、正文、图片与页脚同一单栏宽度；每个入口只出现一次（社交与 RSS 在页脚，回到顶部只在页脚）；不新增多套皮肤、独立欢迎页或像素级搭建器。扩展接口见 [EXTENDING.md](EXTENDING.md)。
3. **快**：访客页面默认只加载同源资源；字体只有拉丁字符的 63 KB；图片按屏幕宽度下载。
4. **可读**：文字对比度目标 ≥ 4.5:1；中文正文行高 1.8；独立按钮、图标与页脚操作区域 ≥ 44px。

## 变量（`assets/css/tokens.css`）

| 类别 | 值 |
|---|---|
| 颜色 · 浅色 | 底 `#fbfcfd` · 字 `#1f2733` · 次要 `#5d6878` · 线 `#dfe5eb` · 强调 `#c2410c`（橙） |
| 颜色 · 深色 | 底 `#18202b` · 字 `#e6ebf2` · 次要 `#a4b0c0` · 线 `#303c4b` · 强调 `#ff8f4d`（橙） |
| 强调色可选 | `accent`：orange 橙（默认）· blue `#0b6aa8`/`#6ec2f0` · teal `#0f766e`/`#3cc8b4` · rose `#be123c`/`#fb7185` · violet `#6d28d9`/`#a78bfa`；均 ≥ 4.5:1 |
| 字体 | Google Sans Code（拉丁）→ 苹方 / 微软雅黑 / Noto Sans CJK（中文） |
| 字号 | 12 / 14 / 16（正文）/ 18 / 20 / 24 / 26–30（文章标题）/ 36–48（首页大标题） |

| 宽度 | 全站 48rem（页头、正文、图片、页脚对齐），图片不超出正文栏 |
| 间距 | `--space-1`…`--space-8` = 0.25 / 0.5 / 0.75 / 1 / 1.5 / 2 / 3 / 4 × `--spacing-unit` |
| 动效 | 160ms（悬停）· 320ms（菜单、图标）· 先快后慢的减速曲线 |

## 页面

| 页面 | 结构 |
|---|---|
| 首页 | 首屏无卡片：网站描述 → 大标题 → 介绍 → 开始阅读（文字链接），宽屏线描在右、窄屏在上 → 原有首页挂件插槽 ─ 精选（最多 3 篇，已在本页“最近”的不重复）─ 最近（分页）→ 全部文章 |
| 文章 | ← 返回 → 强调色标题 → 日期（图文加照片数）→ 导语 → 目录（≥ 3 个小标题）→ 正文 ─ 上一篇 / 下一篇 → 可选邮件订阅 → 按需加载评论（两项均默认关闭） |
| 归档 | 标题 + 总篇数 → 年份（篇数）→ 月份 → 每篇一行（标题在左、“日”在右；机器可读时间保留完整） |
| 关于 / 友链 / 致谢 | 标题 → 真实发布/更新时间（有值时）→ 正文或纯文字列表；新页面复用页头/页脚和通用布局 |

## 组件

| 组件 | 规格 |
|---|---|
| 页头 | 站名（粗体）在左，导航在右，当前文字页波浪下划线，首页图标以强调色指示；吸顶、半透明；底部细线与正文同宽。手机：搜索（启用时）、太阳/月亮 + 菜单，展开为居中链接列表。宽屏一行放不下时（导航名很长、浏览器翻译成外语、放大）也收进菜单，页头不折成两行；站名标为不翻译 |
| 深浅色按钮 | 太阳 → 月亮：遮罩圆滑入切出月牙，光芒旋转收起，500ms |
| 列表项 | 标题（强调色，悬停虚线）· 日历图标 + 斜体日期 · 一行摘要 |
| 链接 | 正文中虚线下划线；悬停变强调色、下划线变实 |
| 图片 | 单张与正文同宽；同段多张等高并排（按比例，不裁切）；所有文章类型都不超出正文栏；点开放大 |
| 页脚 | 居中纵向：一句话（有值时）→ 社交与 RSS 图标（可选邮件订阅）→ 版权 → 技术 / 模板回链 → 回到顶部。站名只在页头；保留全部原开关，无入口时不留空行 |
| 上传图标 | 位图重编码、被动 SVG 以独立图片发布，亦可显式选择 HTTPS 外链；视觉框内保留比例，按钮至少 44px；社交图标按配置顺序自动换行 |
| 可选挂件 | 首页介绍后 / 正文后 / 页脚前三个插槽；同处按配置排序。搜索默认开、答案之书默认关，不使用卡片式大容器 |

## 交互

| 交互 | 行为 | 无障碍 / 降级 |
|---|---|---|
| 菜单 | 点三条线展开（变 ×）；Esc、点外面、点链接、Tab 离开页头、页头重新放得下时收起。矮窗口里菜单不超出屏幕，在菜单内滚动 | `aria-expanded`；键盘打开时焦点进入第一项，可按顺序走完并自然离开；Esc 后焦点回按钮；布局切换藏起当前焦点时交给可见的按钮或导航项，不抢正文焦点；无 JS 时导航常显、页头随页面滚动，避免换行后遮挡锚点 |
| 深浅色 | 首次绘制前应用；选择存本机 | 无 JS 时跟随系统 |
| 点图放大 | 原生 `<dialog>`；方向键 / 滑动切换 | 无 JS 时链接直接打开大图；焦点归还 |
| 开始阅读 | 原生同页 `#recent-title` 链接，不创建入场页或加载脚本 | 可键盘 / 触控；最近标题接收焦点，继续 Tab 到文章；无 JS 仍有效 |
| 回到顶部 | `#top`（页面中没有 `id="top"`，浏览器按规范滚到页首），平滑滚动 | 减少动态效果时直接跳 |
| 图标反馈 | 悬停/键盘聚焦时轻移、旋转、缩放；CSS 变量可改 | 不改变布局；减少动态效果时禁用变换，信息不依赖动效 |
| 搜索 | 首次输入取本站索引，中文子串、多词匹配；可用时不重复显示归档入口（导航已有） | 失败可重试并显示归档入口；无 JS 时保留归档，无失效输入框 |
| 答案之书 | 点按钮翻一句，不连续重复 | 无 JS 保留静态句子；不要求输入问题、不保存数据 |
| 页面切换 | 同源跳转淡入淡出（View Transitions） | 不支持或减少动态效果时直接跳转 |

## 断点

≤ 44rem：首屏线描移到文字上方并缩小。≤ 40rem，或站名 + 导航一行放不下时：有 JS 时导航收进菜单（按实际宽度判断，不识别翻译器）。页脚始终居中，各行按宽度自动换行。
