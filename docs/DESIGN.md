# 设计基线与可选扩展

阅读页与文章列表沿用 v1.0 的文字单栏、等宽字体、强调色标题列表和虚线链接。首页欢迎区分栏、页脚分组，作者已于 2026-10-19 确认样式验收，随本次更新交付。样式与线描独立编写；参考与边界见 [RESEARCH.md](RESEARCH.md)，取舍见 [DECISIONS.md](DECISIONS.md)，日常修改见 [CUSTOMIZE.md](CUSTOMIZE.md)。

## 原则

1. **文字和照片仍是主角**：文章列表和阅读页不加卡片、阴影、标签或装饰动画；仅首页欢迎区使用轻纸面边框和静态线描。
2. **一种基线**：欢迎区与页脚按屏幕宽度调整，正文保持单栏；不新增多套皮肤、独立欢迎页或像素级搭建器。扩展接口见 [EXTENDING.md](EXTENDING.md)。
3. **快**：访客页面默认只加载同源资源；字体只有拉丁字符的 63 KB；图片按屏幕宽度下载。
4. **可读**：文字对比度目标 ≥ 4.5:1；中文正文行高 1.8；独立按钮、图标与页脚操作区域 ≥ 44px。

| 类别 | 值 |

## 页面

| 页面 | 结构 |
|---|---|
| 首页 | 欢迎区：线描 / 网站描述 / 大标题 + RSS；现有介绍 / 开始阅读 / 社交 → 原有首页挂件插槽 ─ 精选（最多 3 篇）─ 最近（分页）→ 全部文章 |
| 文章 | ← 返回 → 强调色标题 → 日期（图文加照片数）→ 导语 → 目录（≥ 3 个小标题）→ 正文 ─ 回到顶部 · 上一篇 / 下一篇 → 可选邮件订阅 → 按需加载评论（两项均默认关闭） |
| 归档 | 标题 + 总篇数 → 年份（篇数）→ 月份 → 紧凑列表（标题 + 日期） |
| 关于 / 友链 / 致谢 | 标题 → 真实发布/更新时间（有值时）→ 正文或纯文字列表；新页面复用页头/页脚和通用布局 |

## 组件

| 组件 | 规格 |
|---|---|
| 页头 | 站名（粗体）在左，导航在右，当前文字页波浪下划线，首页图标以强调色指示；吸顶、半透明；底部细线与正文同宽。手机：搜索（启用时）、太阳/月亮 + 菜单，展开为居中链接列表 |
| 深浅色按钮 | 太阳 → 月亮：遮罩圆滑入切出月牙，光芒旋转收起，500ms |
| 列表项 | 标题（强调色，悬停虚线）· 日历图标 + 斜体日期 · 一行摘要 |
| 链接 | 正文中虚线下划线；悬停变强调色、下划线变实 |
| 图片 | 单张大图；同段多张等高并排（按比例，不裁切）；图文文章宽于正文栏；点开放大 |
| 页脚 | 站名 / 原有个人文字，与社交 / RSS 分组；下方版权 / 原有技术及模板回链 / 回到顶部。手机堆叠，保留全部原开关，无联系入口时不留空分组 |
| 上传图标 | 位图重编码、被动 SVG 以独立图片发布，亦可显式选择 HTTPS 外链；视觉框内保留比例，按钮至少 44px；社交图标按配置顺序自动换行 |
| 可选挂件 | 首页介绍后 / 正文后 / 页脚前三个插槽；同处按配置排序。搜索默认开、答案之书默认关，不使用卡片式大容器 |

## 交互

| 交互 | 行为 | 无障碍 / 降级 |
|---|---|---|
| 手机菜单 | 点三条线展开（变 ×）；Esc、点外面、点链接、屏幕变宽收起 | `aria-expanded`；Esc 后焦点回按钮；无 JS 时导航常显、页头随页面滚动，避免换行后遮挡锚点 |
| 深浅色 | 首次绘制前应用；选择存本机 | 无 JS 时跟随系统 |
| 点图放大 | 原生 `<dialog>`；方向键 / 滑动切换 | 无 JS 时链接直接打开大图；焦点归还 |
| 开始阅读 | 原生同页 `#recent-title` 链接，不创建入场页或加载脚本 | 可键盘 / 触控；最近标题接收焦点，继续 Tab 到文章；无 JS 仍有效 |
| 回到顶部 | `#top`（页面中没有 `id="top"`，浏览器按规范滚到页首），平滑滚动 | 减少动态效果时直接跳 |
| 图标反馈 | 悬停/键盘聚焦时轻移、旋转、缩放；CSS 变量可改 | 不改变布局；减少动态效果时禁用变换，信息不依赖动效 |
| 搜索 | 首次输入取本站索引，中文子串、多词匹配 | 失败可重试；无 JS 时保留归档，无失效输入框 |
| 答案之书 | 点按钮翻一句，不连续重复 | 无 JS 保留静态句子；不要求输入问题、不保存数据 |
| 页面切换 | 同源跳转淡入淡出（View Transitions） | 不支持或减少动态效果时直接跳转 |

## 断点

≤ 44rem：欢迎区上下堆叠。≤ 40rem：有 JS 时导航收进菜单。≤ 36rem：页脚上下分组。≥ 66rem：图文文章宽图。
