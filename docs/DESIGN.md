# 设计定稿（v1.0）

风格参考 AstroPaper：文字优先的单栏、等宽字体、强调色标题列表、虚线链接。样式为独立编写。取舍理由见 [DECISIONS.md](DECISIONS.md)，日常修改见 [CUSTOMIZE.md](CUSTOMIZE.md)。

## 原则

1. **只有文字和照片是主角**：没有卡片、阴影、标签、装饰动画。
2. **一种样式**：不提供风格或布局选项，只提供内容（文字、链接、开关）和强调色。
3. **快**：访客页面只加载同源资源；字体只有拉丁字符的 63 KB；图片按屏幕宽度下载。
4. **可读**：所有文字对比度 ≥ 4.5:1；中文正文行高 1.8；触控区域 ≥ 44px。

## 变量（`assets/css/tokens.css`）

| 类别 | 值 |
|---|---|
| 颜色 · 浅色 | 底 `#fbfcfd` · 字 `#1f2733` · 次要 `#5d6878` · 线 `#dfe5eb` · 强调 `#c2410c`（橙） |
| 颜色 · 深色 | 底 `#18202b` · 字 `#e6ebf2` · 次要 `#a4b0c0` · 线 `#303c4b` · 强调 `#ff8f4d`（橙） |
| 强调色可选 | `accent`：orange 橙（默认）· blue `#0b6aa8`/`#6ec2f0` · teal `#0f766e`/`#3cc8b4` · rose `#be123c`/`#fb7185` · violet `#6d28d9`/`#a78bfa`；均 ≥ 4.5:1 |
| 字体 | Google Sans Code（拉丁）→ 苹方 / 微软雅黑 / Noto Sans CJK（中文） |
| 字号 | 12 / 14 / 16（正文）/ 18 / 20 / 24 / 26–30（文章标题）/ 36–48（首页大标题） |
| 行高 | 界面 1.6；正文 1.8 |
| 宽度 | 全站 48rem（页头、正文、页脚对齐）；图文文章宽图 64rem |
| 间距 | `--space-1`…`--space-8` = 0.25 / 0.5 / 0.75 / 1 / 1.5 / 2 / 3 / 4 × `--spacing-unit` |
| 动效 | 160ms（悬停）· 320ms（菜单、图标）· 先快后慢的减速曲线 |

## 页面

| 页面 | 结构 |
|---|---|
| 首页 | 大标题 + RSS 图标 → 介绍（可含链接）→ 「在别处」图标 ─ 精选（最多 3 篇）─ 最近（分页）→ 全部文章 → |
| 文章 | ← 返回 → 强调色标题 → 日期（图文加照片数）→ 导语 → 目录（≥ 3 个小标题）→ 正文 ─ 回到顶部 · 上一篇 / 下一篇 |
| 归档 | 标题 + 总篇数 → 年份（篇数）→ 月份 → 紧凑列表（标题 + 日期） |
| 关于 / 友链 / 致谢 | 标题 → 正文或纯文字列表 |

## 组件

| 组件 | 规格 |
|---|---|
| 页头 | 站名（粗体）在左，导航在右，当前页波浪下划线；吸顶、半透明；底部细线与正文同宽。手机：太阳/月亮 + 三条线菜单，展开为居中的大号链接列表 |
| 深浅色按钮 | 太阳 → 月亮：遮罩圆滑入切出月牙，光芒旋转收起，500ms |
| 列表项 | 标题（强调色，悬停虚线）· 日历图标 + 斜体日期 · 一行摘要 |
| 链接 | 正文中虚线下划线；悬停变强调色、下划线变实 |
| 图片 | 单张大图；同段多张等高并排（按比例，不裁切）；图文文章宽于正文栏；点开放大 |
| 页脚 | 居中：一句话（斜体）→ 社交图标 + RSS → 版权 → 回到顶部 |

## 交互

| 交互 | 行为 | 无障碍 / 降级 |
|---|---|---|
| 手机菜单 | 点三条线展开（变 ×）；Esc、点外面、点链接、屏幕变宽收起 | `aria-expanded`；Esc 后焦点回按钮；无 JS 时导航直接显示 |
| 深浅色 | 首次绘制前应用；选择存本机 | 无 JS 时跟随系统 |
| 点图放大 | 原生 `<dialog>`；方向键 / 滑动切换 | 无 JS 时链接直接打开大图；焦点归还 |
| 回到顶部 | `#top`（页面中没有 `id="top"`，浏览器按规范滚到页首），平滑滚动 | 减少动态效果时直接跳 |
| 页面切换 | 同源跳转淡入淡出（View Transitions） | 不支持或减少动态效果时直接跳转 |

## 断点

≤ 40rem：导航收进菜单。≥ 66rem：图文文章宽图。
