# 取舍与不做清单

判断方法：降低记录阻力、提高阅读体验或保护隐私的收益，应大于开发、长期维护和每次使用多出来的选择。v1.0 的取舍是历史背景，本轮重新评估了搜索、图标、有界扩展和首页/页脚层次；旧决定不构成永久禁令。

## 核心模板一定不加入

指本项目核心维护范围；使用者可以自行开发，但不会由模板为任意扩展背书。

| 事项 | 边界与理由 |
|---|---|
| 自建 CMS、登录/OAuth 后端、数据库或插件市场 | 文件 + Git 已提供存储/版本，Sveltia 可替换；不为单人写作再维护服务、账号与权限系统 |
| CMS 任意 HTML/JS、上传 SVG 安装插件、任意远程脚本/iframe 注入 | 这是执行代码而非配置。访客页面与 `/admin/` 同源，需要守住令牌和 CSP 信任边界 |
| 内建完整 ActivityPub 服务、联邦收件箱、自动跨站发帖/Webmention 收件 | 需要签名、队列、重试、凭证、反垃圾与持续运行；本模板只提供静态身份认证和分享署名，不把它们冒充联邦发布 |
| 内建点赞、浏览计数、统计、广告和追踪 | 不符合安静阅读；会增加隐私、第三方请求和长期维护负担。第三方脚本尤其会扩大同源风险 |
| GitHub Actions / 定时重建 / 自动重试 / 无人值守上游更新 | 已有 Workers Builds 单一发布路径；额度是账户共享资源，不是无限免费。更新要可审查，不因上游变化自动改生产站 |
| 在线/付费 OG 生成服务、远程搜索或 AI 问答 API | 本地静态生成和浏览器搜索已够；不增加密钥、账单、延迟与服务可用性依赖 |
| 视频、GIF、原始 HEIC/相机文件直接发布 | 体积、元数据和播放器维护成本高；支持的输入应先转静态 WebP，不把原图上站 |
| 像素级拖拽页面搭建器、每篇自选字体/色彩/间距 | 内容和展示层分离；用户选语义类型，而不是每写一段都重新设计网站 |
| 无限滚动、自动播放、持续装饰动画、强制动效 | 不增加阅读价值，可能损害可访问性和性能；仅保留交互反馈并尊重减少动态效果 |
| 自动 AI 改写、打卡、热力图、成长任务 | 把个人记录变成任务；答案之书只是原创短句的可选随机展示，不是 AI 或建议服务 |

## 已做成可选或可配置

| 事项 | 默认 | 维护界限 |
|---|---|---|
| CMS 审核流 | 关闭，simple | 自选 editorial_workflow，权限和保存成本另说明 |
| 搜索 | 启用，首页介绍后 | 本站构建索引，按需读取，2 MiB 上限；可完全关闭 |
| 答案之书 | 关闭 | 原创纯文字，可替换、排序和选择插槽；没有输入收集或远程调用 |
| favicon、导航/社交图标 | 模板 favicon、首页图标；社交为空 | 上传位图重新编码，列表拖动排序；不开放用户 SVG 执行 |
| 外链打开方式 | 新标签 | 全局默认 + 单条覆盖；新标签安全属性不可省 |
| Mastodon 身份/署名 | 模板为空 | 用户填写自己的账号并在 Mastodon 侧完成设置 |
| 自动文字分享图 | 启用 | 优先实际封面，构建期生成；不下载中文字库到访客端 |
| 模板回链 | 只显示 GitHub | 一键关闭，不绑功能；仓库的许可证仍须保留 |
| 强调色、深浅色、图标轻动效 | 橙 / 跟随系统 / 轻量反馈 | 变量和小开关，不发展成多套版式系统 |
| 新页面、挂件、全局行为 | 有界扩展接口 | 代码白名单、职责和回归规范见 [EXTENDING.md](EXTENDING.md) |
| 免登录评论 | 关闭，服务尚未开通 | 博客、读者面板、API/管理端三个源分开；无邮件/邮箱，固定客户端，数据和部署独立，见 [COMMENTS.md](COMMENTS.md) |

## 首页与页脚的重新取舍（2026-10-19 更新）

2026-10-16 将阅读参考单独做成首页/页脚预览，不混进评论开通：欢迎区用原创静态线描、现有文字和原生“开始阅读”，桌面分栏、手机堆叠；页脚按个人表达、联系订阅和版权回链分组。具体参考来源见 [RESEARCH.md](RESEARCH.md)。

这只调整当前版式，不新增皮肤选择、独立欢迎路由、秒级计时、远程图片或脚本。文章列表与阅读页维持文字单栏，旧文章 URL、分页、归档、RSS、搜索以及用户文案/开关保留。无 JS 时导航常显并随页面滚动，避免变高的页头遮住原生阅读锚点；不为此新增测量脚本。2026-10-19 作者已确认样式验收并授权提交、推送；本次交付首页与页脚更新，不因此开通评论服务。

## 评论的重新取舍（本地接入，尚未开通）

2026-10-15 因明确的作者/读者互动需求，改为可选的免登录 Waline 接入，而不是继续将评论永久排除。博客只连接受限的跨源面板，不加载远程评论脚本；读者面板与管理端也分开，旧会话、消息来源和请求范围有检查。默认关闭、主动加载、稳定文章键；不收邮箱或发通知。框架来源是唯一新增的访客 CSP 权限，不放宽脚本和后台策略。

2026-10-16 已按新增运行费 0 元/月目标，准备独立的 Waline + Vercel Hobby + Neon Free 服务包：复用上游账号/审核/存储，只增加严格 TLS、受保护单账号初始化、来源/窗口边界和手动备份，不自研一套后端。不开邮件、不依赖不稳定的 Oracle 实例、不新增定时保活或自动部署。同日按精确改动清单剔除该部署不使用的适配器/依赖，运行与管理端构建审计降到 0；根据准确上游 GPL-2.0 说明交付组件源码，并验证管理端源码归档可重建实际脚本。这带来一次手动分发维护责任，升级必须重审清单、锁文件和源码，不是无成本 fork 或永久安全保证。实际账户与云端仍待授权、配置及验收；本机数据库和浏览器可用不是已经上线。无登录昵称不是可信身份，审核、限速和独立备份不可省。详见 [COMMENTS.md](COMMENTS.md)。

## 暂不做，出现真实需求再评估

| 事项 | 触发条件 |
|---|---|
| 标签、分类、系列、多语言 | 实际作者/内容规模需要，且愿意承担迁移与组合测试；现在归档、搜索、手写阅读地图已足够 |
| 照片联系表、章节直链增强 | 作者照片或长文使用需求稳定后；详见 [RESEARCH.md](RESEARCH.md) 的三个候选，不视为已承诺功能 |
| R2 媒体迁移 | 仓库接近 1 GB 或 Git 操作明显变慢；先评估草稿隔离、密钥和费用，见 [R2_FUTURE.md](R2_FUTURE.md) |
| 更换/自托管 CMS | Sveltia 持续故障、停止维护、CDN 不可用或供应链风险；遵守内容契约，不改变站点生成方式 |
| 并存的多套首页或视觉预设 | 本轮只调整单一欢迎区和页脚；不因设计参考增加多套布局开关，让组合测试成倍增长 |

## 保留的 v1.0 历史取舍

曾删除多套风格预设、大体积网页中文字体、卡片首页、轮播、滚动渐显、固定侧栏目录、头像和每篇排版选项；这些不因本轮扩展接口重新回到核心。保留的是单栏、响应式图片、点图放大、可折叠目录和稳定链接。

本轮的改变是把低成本、高频使用的能力做成有明确边界的设置/组件，而不是不断增加后端或分支版式。首页的纸面式欢迎区不代表恢复卡片文章列表或装饰动画。新增事项须先说明默认值、关闭态、隐私/性能预算和维护方式，再讨论实现。
