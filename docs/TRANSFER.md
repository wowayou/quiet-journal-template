# 内容导入、导出与迁移

内容工具只在本机处理 Quiet Journal 快照，不操作 Git、不读取 CMS 令牌、不向外部上传，也不会自动合并或发布。新版入口为 `npm run content:ui`；原命令行格式仍兼容。2026-10-22 两仓本地实现/验收并提交，未推送部署。需要 Node.js 18+ 并先 `npm ci` 安装锁定依赖，推荐 Node 24。

## 推荐：图形内容工具

1. 先保存后台工作，自行同步本地仓库并暂停同时编辑。在博客仓库根目录运行 `npm run content:ui`，打开终端显示的完整 `127.0.0.1` 地址。
2. **导出**：查看文章、普通页面、图片/图标、体积摘要；可选择是否包含内容设置。确认私人内容后生成 ZIP 或目录，完成态给出实际路径、复制入口和 ZIP 下载。草稿、未来文章、未引用图片明确包含，不把“快照”误当公开分享包。
3. **导入**：选择/拖放 ZIP，或选择存放目录中的旧版快照、填写外部目录完整路径。文件只传到本机服务的私密临时目录；选择后自动检查。比较可筛选、查找、分页，Markdown/YAML 可查看转义后的纯文本，并下载完整报告。
4. 勾选“已查看比较结果”后，恢复到新的隔离目录；**当前博客不变，原有草稿/公开标记保留**。内容不同不是损坏，不自动选择哪一方。

默认存放位置是仓库的上一级目录。可先建立私人目录，再运行 `npm run content:ui -- --folder /私人目录`。不能位于 Git/Hugo 工作区，不开放局域网/公网监听。它不是手机在线整库后台，电脑须有本地仓库。

### 会话、状态与中断

- 本机随机端口、精确 Host/Origin、独立随机会话；密钥最初放地址片段，打开即从地址栏移除。只存当前 tab 的 sessionStorage（会话存储）用于刷新恢复，不用持久 localStorage，也不与 CMS 共用源。
- 一次只执行一个内容操作。相同 operation ID 重复请求返回同一任务，不再次写入；主页面与后台工作线程分开，按真实检查/复制/打包阶段显示状态，不估算假百分比。
- 页面刷新保留任务和已完成比较；只在任务活跃时每秒查询，最多 130 次，不轮询外部服务。切换/关闭页面会停止该页查询，但不等于服务端任务取消；使用取消按钮或终端 Ctrl+C。
- 任务限两分钟，取消先合作清理，卡死时停止工作线程并提示检查残留。超时/断网可能发生在完成后，**先刷新核对原任务，不盲目重新导入或导出**。
- 检查结果绑定内容包与比较目标的实际文件哈希。检查后同名包被换成另一份有效包、本站增删/修改文件，旧确认都会失败；恢复过程再次复核，变化时清理新输出。
- ZIP 下载交给浏览器原生流式下载，不将 1 GiB 内容载入页面 Blob。短期一次性下载地址与 HttpOnly/SameSite cookie 双重绑定，一分钟失效，不暴露会话密钥；结束后 cookie 删除。JSON 比较报告较小，由页面下载。

工具不能对抗同一用户权限的恶意本机程序或所有竞态，文件权限也不是加密。不要让其他程序在复制期间改写来源/目标。

## 包含与排除

保留原始字节、文件路径、UTF-8/换行、文首元数据、稳定 ID 和图片引用：

- `content/**` 中 Markdown 和 JPEG/PNG/WebP，包括草稿、未来文章、普通页面及未引用随文图片。
- `assets/media/**` 中 JPEG/PNG/WebP，以及通过被动图标白名单的 SVG（≤256 KiB）。
- 可选 `data/site.yaml`、`links.yaml`、`widgets.yaml`、`answers.yaml`。默认包含，GUI 可关；外链图片只保留文字地址，不自动下载。

不包含 `.git`、`.env`、CMS 令牌或编辑器连接、核心/扩展代码、Hugo/Worker/DNS 配置、构建缓存、`data/comments.yaml`、`data/newsletter.yaml`、`data/editor.yaml`、服务配置及数据库归档。文章内的 `comments` 开关原样保留。评论数据库与邮件订阅者名单独立备份，见 [COMMENTS.md](COMMENTS.md)、[研究中的订阅说明](RESEARCH.md)。

**不是公开分享包、完整站点或历史备份。** 不能识别正文或设置中自己写的密码、人物或地点；即使文件元数据干净，照片画面仍需审查。写操作须显式私人内容确认，命令行用 `--include-private`。

## 文件格式与限额

目录格式不变：`manifest.json` + `files/`。ZIP 根也只有这两部分，解包后使用同一校验引擎；不是万能 ZIP 解压程序。

`manifest.json` 格式 `quiet-journal-content`、版本 1，包含创建时间、私人声明及每个文件的路径/字节数/SHA-256。最终清单最后写入；导入目录有 `IMPORT-REPORT.json`，任务根另保留比较报告。缺少完成标志不能算成功。

| 项目 | 限额/检查 |
|---|---|
| 内容文件 | 最多 10,000 个、单文件 25 MiB、总量 1 GiB |
| 清单 | 4 MiB，拒绝未知版本/字段、非法大小/校验值 |
| 路径 | 最多 16 段、1,024 UTF-8 字节；绝对/上级/隐藏/保留名称、大小写/Unicode、目录文件冲突都拒绝 |
| 媒体 | EXIF/XMP/IPTC、HEIC、动图、正文 SVG、主动 SVG、未知类型拒绝，不因迁移跳过 |
| ZIP | 压缩输入最多 1 GiB + 8 MiB；实际解压字节限额、单文件压缩比 >200（且 >1 MiB）拒绝、两分钟上限 |
| ZIP 特性 | 只接受 stored/deflate；拒绝加密、符号链接/设备文件、嵌套包/代码、重复条目、路径穿越；CRC 和实际大小也检查 |
| 文字比较 | 每侧最多 256 KiB，纯文本转义，不执行 HTML、JS 或短代码 |
| 本机资源 | 一工作线程，堆限制 192 MiB；最多保留 40 个任务记录，存放目录最多列一层 2,000 项 |

输出全新且位于站点外，已有空目录也不覆盖；目录权限 700，文件 600（支持 POSIX 的系统）。ZIP 默认用 stored，避免二次压缩照片和极端压缩比，文件时间归一，不带本机用户名。ZIP 便于携带，不承诺压缩节省或加密。

## 原命令行接口

```sh
npm run content:export -- --output ../journal-content --include-private
npm run content:inspect -- --source ../journal-content --compare .
npm run content:import -- --source ../journal-content --output ../journal-review --include-private
```

父目录必须已存在，输出全新且不在站点/Git/Hugo 工作区。`inspect --compare` 返回新增/相同/冲突/本站独有，不覆盖；退出码 0 无冲突，2 有比较冲突，1 参数/校验/操作失败。命令行仍使用旧目录契约；ZIP 是 GUI 的便利层，不悄悄改变旧命令语义。

## 隔离恢复之后

1. 保管当前站点独立备份，在更新分支逐项决定文章、共享图片和内容设置；不把整个包覆盖到站点。
2. 拿不准的文章先设草稿；来源文章 ID 和正文域名原样保留，不等于在不同 permalink 规则下网址必然一致。
3. 用可信目标代码运行 `npm run build` 并核对日期、导航、图片、草稿隔离、RSS/搜索与旧 URL；不执行包内代码。
4. 审查 diff 后再决定提交/推送，推送仍会用既有云端构建额度。不为每个导入文件单独触发构建。

WordPress、Notion、任意插件转换、公开内容发布包、完整 Git 恢复和外部评论/邮件迁移不是本工具范围。Buttondown 通用归档导入不保留博客 `draft`，**不能直接把私人快照送给它**。

## 验证

`npm test` 包含原有往返、路径/媒体/篡改/覆盖/清理与新增 ZIP、确认一致性、任务幂等/取消、原生下载许可回归。新增真实有效包突变、复制中目标变化、慢上传的取消/超时/断线与清理，以及 ZIP CRC、加密、特殊条目、压缩方法、实际大小、目录/Unicode 冲突的独立用例。Markdown 的大小写扩展名使用同一摘要/文字比较契约，未检查条目与比较来源变化仍拒绝。`QJ_CHROMIUM=/本机/chrome npm run test:transfer` 检查真实界面点击、126 条比较分页/搜索、文字弹窗、完整报告与原生 ZIP 下载、选择/拖放、比较/恢复、刷新中断和 SVG；不下载浏览器、不修改远程。大型包、最大容量的耗时/RSS 内存及真实设备仍须按实际使用环境验收，不把容量上限当性能保证。
