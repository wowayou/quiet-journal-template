# 评论：免登录、独立面板与 Waline 服务

更新：2026-10-16。已实现**本地隔离面板、独立服务分发与真实 PostgreSQL/管理端浏览器回归**；原依赖告警已处理，GPL-2.0 对应源码及离线重建已验证。模板及当前实例的评论仍默认关闭，**尚未创建或部署云端面板、服务和数据库，也没有发送真实邮件**；账户、云端与真机仍须验收。

## 邮件费用是什么？可以不要吗？

可以不要。留言、作者回复和读者回来查看都不依赖邮件。费用通常来自“有新评论通知作者”“有人回复通知读者”的发送服务；还可能涉及注册验证和找回密码。**计量单位是邮件，不是评论**，一条互动可能产生多封通知。

本版选择：**读者不填邮箱、不登录、不发通知邮件**。作者在独立的 Waline 管理端审核/回复；读者主动回来查看。没有后台自动发信、邮件任务或重试队列。服务端也必须保持 SMTP（Simple Mail Transfer Protocol，邮件发送协议）未配置，不能只隐藏前端邮箱输入。

核对时的例子（不是本账户的套餐或未来价格保证）：

| 选择 | 费用与边界 |
|---|---|
| 不启用邮件（本版） | 无通知邮件发送费用；评论服务/数据库分别核对免费额度，可以在符合条件和限额时为 0 元 |
| Resend Free | 当前每月 3,000 封、每天最多 100 封；小站可能够用，但突发量也受每日限制 |
| Resend Pro | 当前 $20/月起，含 50,000 封；超额按量功能需另行启用，不能默认允许自动扣费 |
| 现有邮箱 SMTP | 是否允许网站通知、额度/反滥用条款需按具体邮箱核对，不视为免费无限或保证送达 |

以后确实需要通知时，再选择发信服务、核对域名验证与额度、加明确的订阅/退订和发送上限。发信凭据只在评论服务端保存，**不进入 Hugo、CMS 配置、面板 JSON 或内容包**。不覆盖既有发信域名记录；也不为一个评论功能先开付费邮件套餐。

## 三层分开，而不是把第三方程序插入博客

```text
博客（Hugo 静态站）
  └─ 读者点击后：受限的跨源 iframe → 独立评论面板
                                      └─ 匿名 GET / POST → Waline API + 管理端
                                                             └─ 评论数据库
```

三个源（协议、域名、端口的组合）必须不同：

- **博客源**：只保存面板的公开 origin 和文章评论开关。不知道数据库、API 或邮件凭据，不执行 Waline 客户端。
- **面板源**：只承载免登录读者界面，固定版本客户端自托管，不使用运行时 CDN。它不能读取博客或写作后台的浏览器存储。
- **API / 管理端源**：Waline 提供存储、审核、作者身份和回复；作者在这里登录。管理会话不与读者面板共享。

当前 `/admin/` 仍沿用已有部署，**本轮没有擅自迁移后台域名或登录状态**。评论的安全隔离不依赖先搬后台：博客不新增第三方脚本，面板与博客、管理端均跨源。以后若拆出写作后台，需要独立处理 `site_url`、旧入口、旧源中残留的令牌和重新登录，不能只改个链接就宣称完成。

`integrations/waline/` 是可独立构建、复制和部署的静态面板；`integrations/waline-server/` 是另外的 Waline 服务包装，两者都不进入 Hugo 的 `public/`。博客更换评论服务时只需保留面板协议和文章键，或者关闭整个功能；文章仍是原来的 Markdown。服务包装复用 Waline 的账号、存储和评论 API，不重新实现一套。

## 已实现的默认行为

- **默认关闭**。开启后只在允许留言的公开文章详情页显示入口；首页、归档、普通页面、RSS、搜索和 Hugo 本地服务器不初始化评论。草稿、未来、过期、`noindex` 或 `comments: false` 的文章不提供入口。
- 开启评论的文章会加载小型同源桥接脚本；点击前不创建面板 iframe、不加载 Waline 客户端，也不请求头像或评论 API。无 JavaScript 时保留“在独立窗口留言”，不显示失效加载按钮；独立面板本身仍需要 JavaScript。
- iframe 不允许导航父页；`Referrer-Policy: no-referrer` 不转发文章网址中的查询信息。文章键放在片段中，不作为面板 HTML 请求的查询参数。
- 父页只接受固定 origin **且来自当前 iframe 窗口**的版本化 ready/error 消息；不接收 HTML、令牌、评论正文或跳转指令。主题只发 light/dark，切换不重建面板、不丢输入或重置文章键。
- 面板首次加载最多等 12 秒。失败明确提示、移除框架，不轮询和自动重试；用户可手动重试。关闭会销毁 iframe，未发文字可能受浏览器存储限制，已发留言不会撤回。
- 免登录只需要昵称和正文；昵称不是身份认证。每页最多 10 条主评论及其回复，主动加载后续页；回复很多时仍受总响应体积上限约束，不把 10 条主评论误当成固定字节量。正文最多 2,000 字符，昵称最多 60 字符。
- 传输适配器只允许当前文章的 `GET /api/comment` 与 `POST /api/comment`，拒绝认证头、其他端点/方法和重定向，使用 `credentials: omit`。请求正文最多 12 KiB，响应最多 1 MiB，请求与响应体读取共用 15 秒超时。
- 不转发缓存邮箱、个人网址或 Waline 额外生成的设备详情；清除**面板自身**的旧登录状态，拒绝带查询令牌的入口。关闭登录按钮本身不够，这些限制有独立测试。
- 不提供上传、评论图片/头像、远程表情搜索、点赞/热度排序、浏览计数或评论 RSS 入口。面板 CSP 禁止图片、第三方脚本和嵌套框架。已有评论正文中的普通链接仍是外部链接，不代表作者背书。
- 失败以面板内可访问文字提示，不依赖跨源 iframe 中可能被浏览器拦截的 `alert`。**超时、断网、响应损坏不等于留言未保存**：提交不会自动重发，先核对列表或联系作者；匿名读者看不到服务端尚未公开的历史待审核内容。

面板不是服务端防火墙，不能阻止别人绕过它直接调用 Waline API。服务端审核、限速、内容清理和访问策略仍然必须配置。

### 免登录不等于匿名或零采集

服务端/托管平台仍可能记录 IP、HTTP User-Agent、访问日志和评论数据。`DISABLE_USERAGENT`、`DISABLE_REGION` 主要控制展示，不能据此声称不保存 IP。本版面板还过滤返回的设备/地区/头像字段，但不会删除服务端日志。

固定客户端在本面板中被限制为**当前窗口的会话存储**，只暂存昵称与同篇待发送文字；不使用持久的 localStorage 来共享待发稿，启动会清理此专用源的旧 Waline 缓存，切换文章也会清除未发送草稿。关闭窗口后不保证保留。浏览器若禁止跨站存储，面板明确失败，可由读者选择独立窗口；尚不能把 Chromium 测试当作 Safari/iPhone 真机通过。

不同源隔离脚本和浏览器存储，但不等于隔离设置了宽泛 Domain 的父域 Cookie。敏感会话不能使用会被发送到评论子域的 Domain Cookie；本版 API 请求也明确不带 Cookie。

## 开通顺序

### 1. 先准备独立的 Waline 数据服务（本地实现，云端未部署）

本轮选择 **Waline + Vercel Hobby + Neon Free**，目标新增运行费 0 元/月，不采购服务器、不启用邮件、不依赖 Oracle。Hobby 限个人非商业使用；免费额度不是永久可用保证，实际套餐/余量需本人确认。服务固定 `@waline/vercel` **1.43.4**、管理端 **0.36.0**，读者客户端仍为 **3.16.1**。

本地部署包、环境变量、费用/停止条件、授权顺序与数据库恢复的唯一操作入口是 [`integrations/waline-server/README.md`](../integrations/waline-server/README.md)。**不要直接点上游一键部署后再补保护，也不要将上游原始环境变量混入本包**；本包只接受 `.env.example` 的专用 `WALINE_*` 配置，审核/禁发信等在代码中固定。

正式开通前至少完成：

1. 先读 [固定上游审查](../integrations/waline-server/UPSTREAM.md)：本地真实移除了不用的 CloudBase/LeanCloud/Akismet 和设备解析依赖，运行树与管理端构建树审计均为 0；按准确上游说明，以 GPL-2.0 交付服务/管理端及其对应源码。后续必须连同固定分发、锁文件、源码归档一起维护，不得只换回官方包或沿用本次报告为未来版本背书。
2. 服务初始为 `locked`，不连接数据库。管理员只在平台保护和独立 Basic 设置口令都生效时注册，随后移除设置口令、切为 `public`，保护旧初始化部署。SQL 唯一约束保证一个作者账号，并发初始化也不能生成两个；公众不能注册。
3. 普通读者先审后显，保留上游 60 秒同 IP 串行节流；这**不是原子并发限流或全站硬预算**。关闭邮件、外部登录、Akismet/验证码转发、统计和 HTTP 数据库迁移端点；作者仍用邮箱格式标识和密码登录，但不发送验证邮件，也没有邮件找回。
4. 精确来源检查与作者令牌权限分开；管理端使用窗口隔离响应头，禁外站登录跳转与查询令牌。不要为了兼容无 Referrer 的同源读取而取消管理认证，也不要让三个源合并。
5. 使用最小权限数据库角色、独立 JWT 密钥和严格 TLS。上游 PostgreSQL 默认 `rejectUnauthorized: false` 的问题已由本包模型工厂修正，本机真实连接验证了错误 CA/主机名会被拒绝；**仍需核验实际 Neon 证书链**，不能只填 `PG_SSL=true`。
6. 在真实服务用非敏感内容再验收留言→待审核→作者审核/回复→读者刷新及独立备份恢复，核对平台代理 IP、实际用量、没有邮件或意外第三方转发。本机结果不等于云端验收。

### 2. 构建与部署独立静态面板

详细打包命令见 [`integrations/waline/README.md`](../integrations/waline/README.md)。配置示意：

```json
{
  "blogOrigin": "https://blog.example.com",
  "panelOrigin": "https://comments.example.com",
  "apiOrigin": "https://waline.example.com"
}
```

这些是公开地址，不是密钥。面板必须挂在自己的根路径；本版不支持带子路径的 Waline API。服务端应使用固定版本、满足接口契约，不自动升级。

面板输出 12 个公开文件，包含同源客户端 JS/CSS、本项目与客户端的完整许可、最小配置与 `_headers`。应部署到能正确应用这些安全响应头的平台；Cloudflare Workers 静态资源可使用该 `_headers`，其他平台必须等价配置，**不能忽略响应头直接开放**。本轮不提供自动创建资源、DNS 或持续部署任务。

### 3. 最后在博客打开入口

确认面板和服务端已验收，再修改 `data/comments.yaml`（或 CMS 的“评论接入”）：

```yaml
enabled: true
origin: "https://comments.example.com"
```

这里只填**面板源，不是 API 地址**。构建会拒绝同源、路径、凭据、非法字段和不安全的地址。某篇不希望留言时：

```yaml
comments: false
```

最后运行博客的 `npm run build`、适用回归，再经发布确认推送；评论开关不会自动替你部署或配置独立服务。

## 文章键、关闭与迁移

评论键为 `/posts/<文章文件名或 bundle 的稳定 ID>/`，不采用标题、公开 `url`、slug 或域名。修改语义地址后原键不变；不同文章不得共用键，冲突会阻止构建。不要重命名有评论的文件 ID；迁移时显式保存键与实际文章地址的映射。

Waline 管理端的文章回链通常由 `SITE_URL` 与评论键拼接。因此将来启用语义网址时，应保留原 ID 地址的重定向，否则评论虽仍对应，管理端的回链可能失效。模板不为此自动改历史地址。

全站关闭会移除入口和资源，并恢复未扩展的访客框架策略；单篇关闭只移除那一篇入口。**关闭入口、撤下或删除文章不会自动删除/锁定服务端评论，也不是禁止直接 API 写入的机制。** 真正停用需在评论服务端关闭写入；管理数据库、公开副本和浏览器草稿各自处理。

## 独立备份，不混进内容导出

- `content-transfer.mjs` 原样保存文章的评论开关，但不包含技术接入配置 `data/comments.yaml`、面板部署配置或 Waline 数据库。
- Git clone、Git bundle 和镜像也不备份外部数据库。保存所选数据库的独立备份及必要版本/配置，凭据另行安全保管。
- 数据备份至少核对评论 ID、文章键、父子回复、作者关联、时间、审核状态；附件/账号等是否覆盖由所选工具确认，不承诺跨系统无损导入。
- 用受保护的临时数据库演练恢复，不往当前生产库直接覆盖；核对待审核内容不被误公开。旧系统停写或准备明确的增量边界后再切换，防止漏评论或重复。
- 评论可能包含私人文字、IP 和账号数据，不把备份放进博客、公开仓库、面板目录或未经审查的在线转换工具。
- 已提供 [独立手动备份与空库恢复流程](../integrations/waline-server/README.md#独立手动备份与恢复)，本机用真实 `pg_dump`/`pg_restore` 验证；没有新增定时任务或自动迁移。正式开通仍需确认负责人、备份频率、保留期、受保护存储位置与实际恢复，Neon 短恢复窗口不能替代它。

## 维护与已验证范围

博客响应头来源已移到 `assets/server/headers.txt`，Hugo 生成最终 `_headers`；保留评论占位符，移除旧 `static/_headers`，双份来源会构建失败。全站评论开启时只允许指定面板的 `frame-src`，博客 `script-src`、`connect-src` 和 `/admin/` 的策略不放宽。不要手工编辑生成的 `public/_headers`。

博客常规构建**不安装或构建 Waline**。面板独立使用 `package-lock.json` 与 `vendor-lock.json` 固定依赖和分发文件哈希；升级需同时审阅客户端、API 契约、静态文件引用、许可并重跑回归，不能改成 `latest`。

本地测试覆盖关闭/开启、无 JS、配置/身份/响应头冲突、匿名字段白名单、请求/响应上限和不重发；另向夹具放入合成的服务环境、项目关联与数据库归档标记，实际构建和内容导出/导入均不带出这些文件，文章评论开关仍按原字节保留。面板浏览器测试使用固定官方客户端、三个本机 HTTPS 源及合成 API，验证提交/回复/分页、待审核显示、存储隔离、旧会话处理、消息伪造、故障/重试、主题和移动触控。

另有独立服务的真实 PostgreSQL 回归：严格 TLS、并发初始化、权限/审核/回复/串行限速、日志和备份恢复；管理端浏览器回归实测表单注册、登录、审核/回复、跨源 opener 隔离与可见源码入口。两个源码附件在同一 API/管理源提供，不含私密配置；管理端附件已在新目录离线重建，输出与实际服务脚本逐字节一致。**服务交互仍为本机合成数据；Vercel/Neon、完整生产链路与 Safari/iPhone 尚未验收，评论仍未上线。**

## 费用与官方依据
