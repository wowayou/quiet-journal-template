返回写作界面

让内容来去自如。

在电脑的博客仓库运行一条命令，打开终端显示的完整地址：

npm run content:ui

工具在这台电脑运行，不读取写作令牌、不上传到外部网站、不操作 Git，也不会发布文章。

导出内容

查看文章、图片和设置摘要，选择 ZIP 或普通目录；勾选私人内容确认后生成内容包。完成页可复制保存路径或直接下载 ZIP。

导入内容

选择或拖放 ZIP，或指定旧版快照目录。工具自动检查，显示新增、相同、内容不同和本站独有文件；可查找、分页、查看文字差异和下载完整报告。确认后只恢复到新的隔离目录，不覆盖当前博客。

快照含草稿、未来文章、未引用图片及个人内容设置。ZIP 不加密；不含主题、部署配置、Git 历史、评论数据库或订阅者名单。不要公开分享。

恢复之后

比较结果继续保留。先人工审查、合并需要的文件，运行 npm run build，再决定提交和发布。导入不是发布，也不是原地恢复整个站点。

存放位置、限额与命令行

默认存到仓库上一级目录；可先创建私人目录，再运行 npm run content:ui -- --folder /私人目录。不能放进 Git/Hugo 工作区；用完 Ctrl+C 关闭。

最多 10,000 文件、单文件 25 MiB、总量 1 GiB；任务限两分钟，失败不自动重试。刷新可恢复本次会话；超时后先核对原任务状态。原命令行内容工具仍保留，详见仓库 docs/TRANSFER.md。
